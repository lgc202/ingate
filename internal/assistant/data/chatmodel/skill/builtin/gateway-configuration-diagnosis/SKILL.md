# 网关配置诊断

## 执行步骤

1. 查询网关入口，确认监听配置、启用状态和生效状态。
2. 查询关联路由，确认路由已挂载到目标网关并处于生效状态。
3. 查询路由引用的服务，确认服务类型、地址数量和生效状态。
4. 只根据工具返回的结果判断问题；信息不足时说明还需要哪些信息。

## 输出要求

- 先说明检查到的事实，再给出判断和建议。
- 建议中说明可能影响，但不要声称已经修改配置。
- 不输出服务凭据、内部地址或其他敏感信息。
