---
title: 流量分析
description: 查看请求趋势、延迟、响应分布和资源排行
---

流量分析使用 ClickHouse 分钟聚合数据展示一段时间内的整体运行情况，不在每次打开页面时扫描全部请求明细。

![Ingate Console 的真实流量分析页面，展示请求趋势、响应分布和资源排行](/ingate/images/screenshots/traffic-analysis.jpg)

## 主要指标

- 请求量与正常响应率
- 客户端错误、服务端错误和无响应
- P50、P95 和 P99 总耗时
- 按 Gateway、Route 或 Service 的请求量与延迟排行

“正常响应”表示最终 HTTP 状态不属于 4xx、5xx，且请求获得了响应；重定向会按 HTTP 结果归类，不等同于请求失败。

页面默认查询最近 1 小时。开始时间和结束时间都是必填项，单次查询不能超过 90 天；可以再按 Gateway、Route 或 Service 缩小范围。

## 趋势图

系统根据时间范围选择分钟粒度聚合。请求量折线展示每个时间桶的请求数；延迟视图展示相同时间桶内的分位数，而不是平均值。

P95 的含义是 95% 请求的耗时不高于该值。样本很少时，P95 接近最大值是正常的；它不应该被解释成平均延迟。查看单次尖峰时应跳转请求记录，并结合 P50/P99 判断分布。

## 从分析到排障

1. 在趋势图发现错误或延迟异常的时间段
2. 在资源排行切换 Gateway、Route 或 Service，缩小范围
3. 进入对应资源的请求记录
4. 打开单条详情确认响应状态、最终端点和转发尝试

分析页面只用于观察和定位问题，不提供配置修改或策略管理。

## 数据来源

Analytics 把请求事实写入 ClickHouse，物化视图同步维护分钟聚合。请求明细可以按保留策略删除，聚合数据默认保留更久，因此长期趋势不会依赖重新扫描已经过期的明细。
